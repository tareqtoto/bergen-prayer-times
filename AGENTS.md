# Monthly update rules

- Use only the official public Bergen Moske Facebook page:
  `https://www.facebook.com/Bergenmoske.no/`.
- Accept an update only when both the public post caption and the timetable
  image clearly identify the same upcoming calendar month.
- Ignore QR codes, comments, unrelated posts or photos, reels, and videos.
- Transcribe every date and all six published columns: Fajr, sunrise
  (`Sol opp`), Dhohr, Asr, Magrib, and Isha.
- Validate the expected month length, uninterrupted date sequence, strict
  `HH:MM` values, chronological time order, official source, and
  `Europe/Oslo` timezone.
- Never calculate, interpolate, infer, or guess a missing or unreadable value.
- If the source is missing, ambiguous, incomplete, or invalid, make no change.
- A successful monthly update may change only `current.json`. Do not change
  repository instructions, validation code, workflows, or other files.
- Retain only one active month. Never present prior-month data as current.
- Do not add Home Assistant configuration, credentials, tokens, addresses,
  personal data, executable web code, or inbound Home Assistant access.
